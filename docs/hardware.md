# Принтер и печатные детали

Проект дисплея разработан на модернизированном Kingroon KP3S Pro S1. Для повторения электроники экрана используются штатный вертикальный TFT24, материнская плата и шлейф, а также Linux-хост с USB–UART.

## Печатные детали

| Деталь | Происхождение и применение |
| --- | --- |
| Печатающая голова и обдув | Creality Sprite в исполнении K3D Ender-3 Sprite Printhead. Исходный проект, модели обдува и варианты креплений — [Дмитрий Соркин, K3D ESP](https://www.k3d.tech/projects/esp/). |
| Крепление каретки к рельсам | Переработано автором этой сборки под установленную рельсовую каретку Kingroon. Исходная конструкция головы — [K3D ESP](https://www.k3d.tech/projects/esp/). |
| Нижний стопор оси Z | Переработан автором этой сборки для Kingroon KP3S Pro S1. |
| Крепление концевика X и датчика окончания филамента | Переработано автором этой сборки для фактического расположения концевика и датчика. |
| Индексные барашки стола | Использована модель `KP3S Pro Bed leveling knob v1`. Автор и исходная публикация пока не установлены. |

Для установленных барашков в модели насчитано 70 внутренних положений на оборот. Резьба M4×0,7 даёт 0,7 мм перемещения за оборот, то есть 0,01 мм за щелчок. Экран показывает направление и округлённое число щелчков в меню регулировки винтов. Для других барашков сверяйте число положений и шаг резьбы перед использованием этого пересчёта.

CAD-файлы перечисленных деталей хранятся отдельно от исходников панели.

## Электроника экрана

Обозначения относятся к MCU штатной платы, а не к разъёму GPIO одноплатного компьютера.

| Узел | Пины |
| --- | --- |
| TFT24, управление FSMC | CS PD7 (NE1), RS PD11 (A16), NOE PD4, NWE PD5 |
| TFT24, линии данных | PD14, PD15, PD0, PD1, PE7…PE15, PD8…PD10 |
| Сброс и подсветка | PC6 и PD13 |
| XPT2046 | CS PA7, SPI2 PB13/PB14/PB15, PB12 для снятия выбора SPI-флеш |

При переносе на другую ревизию проверьте назначение линий по её схеме. Источники распиновки и инициализации перечислены в [SOURCES.md](../SOURCES.md).
