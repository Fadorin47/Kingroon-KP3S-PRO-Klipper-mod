# Установка и откат

## Подготовка

Выполняйте установку в простое, когда сопло и стол выключены. Сохраните текущие конфиги, известный рабочий образ платы и параметры подключения. Проверьте, какой MCU, кварц и загрузчик использует ваш принтер.

| Параметр проверенной конфигурации | Значение |
| --- | --- |
| Исходная ревизия Klipper | `7a723bdc1cb5e292ca0cd7b708035a7249b5e9a7` |
| Целевая сборка MCU | STM32F103, `stm32f103xe` |
| Загрузчик | MKS 28 KiB, начало приложения `0x08007000` |
| Кварц | 8 МГц |
| Подключение к хосту | USART3 PB11/PB10 через USB–UART |
| Скорость для первой установки | 250 000 бод |

Понадобятся рабочий Linux-хост с Klipper, Git, GNU make, ARM GCC, Python 3, Pillow и шрифт DejaVu Sans. На Debian подходящие пакеты называются `git`, `make`, `gcc-arm-none-eabi`, `binutils-arm-none-eabi`, `python3-pil`, `fonts-dejavu-core`. Для службы автозапуска поместите исходники в `~/kingroon-tft24-dev`.

## Базовая прошивка

1. Подготовьте отдельную копию исходников Klipper на указанной ревизии с библиотеками Klipper. Создайте в ней `.config` через `make menuconfig`, сверившись с таблицей. Для выбора скорости откройте дополнительные настройки. Текущая установка Klipper на хосте должна использовать совместимую ревизию. Эта команда собирает вариант с экраном и обычную прошивку для отката.

   ```sh
   cd ~/kingroon-tft24-dev
   python3 prepare.py --klipper ~/klipper-build-source --destination ~/kingroon-tft24-build --build
   ```

2. Сохраните `baseline/Robin_nano.bin`. Проверьте совместимость имени файла с загрузчиком платы. Скопируйте `display/Robin_nano.bin` в корень FAT32 microSD, вставьте её в материнскую плату принтера и выполните полный цикл питания. Если хост питается от принтера, сначала штатно выключите Linux. Убедитесь, что конфиг MCU на хосте использует ту же скорость, что прошивка.
3. Дождитесь состояния Klipper `ready`. Проверьте совместимость и включите драйверы. Вторая команда сохраняет копии изменяемых файлов и перезапускает Klipper.

   ```sh
   python3 enable.py
   python3 enable.py --apply
   ```

4. В консоли Klipper выполните `LCD_PROBE`, затем `LCD_TEST_IMAGE`. На проверенном ST7789V с `madctl: 0x00` рамка, ориентация и все три цвета совпали. При неизвестном ID остановитесь и сверьте контроллер, кабель и распиновку.
5. Запустите калибровку и последовательно нажмите пять крестов. Затем запустите панель и проверьте меню в простое.

   ```sh
   python3 panel.py --calibrate
   python3 panel.py
   ```

Для автозапуска завершите ручной запуск и установите поставляемую пользовательскую службу.

```sh
mkdir -p ~/.config/systemd/user
cp kingroon-tft24.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now kingroon-tft24.service
```

Если служба нужна сразу после загрузки хоста без входа в систему, включите `loginctl enable-linger` для пользователя службы. При нестандартном пути к исходникам или сокету поправьте `WorkingDirectory`, `ExecStart` и `ConditionPathExists` в файле службы.

## Ускоренный вариант

`prepare_fast.py` собирает варианты на 500 000 и 1 000 000 бод с приёмом USART3 через DMA. Он использует исходники и базовый `.config` на 250 000 бод в `~/klipper`. Для отдельной копии исходников укажите `--klipper` так же, как для базовой сборки.

```sh
python3 prepare_fast.py --klipper ~/klipper-build-source --destination ~/kingroon-tft24-fast-build
```

После успешной базовой установки остановите панель и Klipper, установите одинаковую скорость в секции `[mcu]` и в выбранной прошивке. Прошейте `Robin_nano.bin` из каталога нужной скорости тем же способом. После загрузки повторно запустите `enable.py --apply`: параметр скорости проверяется при соединении с MCU, а тайминги дисплея настраиваются по константам загруженной прошивки. Проверьте `LCD_TEST_IMAGE` и счётчики `SERIAL_ERRORS` при нескольких сменах страниц.

## Откат

Остановите панель командой `systemctl --user disable --now kingroon-tft24.service`. Когда Klipper отвечает, выполните `python3 enable.py --disable --apply`, чтобы удалить подключение драйверов из конфига. Если Klipper уже недоступен, восстановите рабочий конфиг из своей копии. Для полного отката прошейте сохранённый базовый образ и восстановите соответствующую скорость `[mcu]`.

## Макросы и миниатюры

Панель обнаруживает доступные команды Klipper. Примеры в каталоге `config/` подключаются отдельно, после сравнения с существующими `PAUSE`, `RESUME`, `CANCEL_PRINT`, `LOAD` и `UNLOAD`. До включения проверьте параметры парковки, ограничения экструзии и имена датчиков для своего принтера.

Для OrcaSlicer можно задать `148x148/PNG` в поле «Эскизы в G-коде». Панель читает встроенное изображение из загруженного файла, сохраняя пропорции. Для отображения прогресса слайсера оставьте включённой генерацию `M73`.
